# 本地登录与设置向导

用户已确认[向导流程](SETUP-WIZARD-DESIGN.md)，本轮已实现独立 Tk 桌面窗口，并接入现有 CloudAuth、系统凭据库、设备发现、Session 和采集器。窗口中的登录和开始监控会使用真实云入口；请只在自己的电脑窗口输入秘密，不发到聊天中。真实账号、系统密钥库读写与目标机型仍待本机联调，离线测试不代表云协议已通过。

## 启动

在项目目录中运行：

```sh
.venv-gui/bin/python -m bambu_monitor setup
```

本机已经创建带 Tk 9 的 `.venv-gui` 并安装项目 `dev,cloud` 依赖，也可以在 Finder 双击项目根目录的 [start-monitor.command](../start-monitor.command)。启动器只选择本项目中带 Tk 的虚拟环境，不修改系统 Python，不安装开机任务。

其他电脑需要 Python 3.11+、Tk 和项目 cloud 依赖。先确认所用 Python 能执行 `python -c 'import tkinter'`；再用该解释器创建虚拟环境并安装：

```sh
python -m venv .venv-gui
.venv-gui/bin/python -m pip install -e '.[cloud]'
.venv-gui/bin/python -m bambu_monitor setup
```

macOS 的部分 pyenv Python 没有编入 Tk；可使用已带 Tk 的 Python 发行版重新建项目虚拟环境。Linux 通常需对应 Python 的 tkinter 系统包。当前安全设置文件实现仅支持 POSIX；Windows明确报错，不能依据 Tk 或 Windows 密钥库后端推导整个向导已经支持 Windows。本机当前使用现有 uv 管理的 Python 3.15.2 / Tk 9，未更改系统安装。

可指定普通设置文件：

```sh
.venv-gui/bin/python -m bambu_monitor setup --config /your/private/directory/provider.toml
```

已有机器可读 `login / collect / logout / check-config / replay` 命令继续可用，详见[云采集说明](CLOUD-COLLECTOR.md)。图形入口不会把规范化快照打印到 stdout；如需 NDJSON 导出使用 collect。

## 首次使用

1. 选择中国大陆或全球账号区域，程序不会按电脑位置猜测。
2. 中国大陆区域输入手机号或邮箱；全球区域使用邮箱。国区手机号填写不带 `+86` 的 11 位大陆号码。可以用密码登录，也可以点击“改用验证码登录”；发码按账号类型选择短信或邮件。发送或重发必须点击“发送一次验证码”，程序不会自动循环发送。密码登录要求验证码时保留账号并进入验证码输入；切换密码／验证码模式也保留账号。网站 TOTP 等其他 MFA 分支当前尚不支持。
3. 从绑定列表明确选择一台打印机，即使只有一台也要选择。列表显示已知机型与设备 ID 尾号，不以列表位置作为身份，也不据绑定列表判断在线。
4. 查看设置保存位置，选择是否把登录令牌放系统密钥库，再确认进入首页。取消不会用未完成设置覆盖旧配置。

新登录先使用内存凭据，确认前不把新令牌写入系统密钥库。确认后，系统密钥库不可用时明确提示仅本次内存；同一窗口仍能继续采集，关闭后需要重新登录。普通设置只保存区域、设备 ID、随机逻辑凭据引用、目标证据阈值及重连策略；不保存手机号、邮箱、密码、验证码、UID 或令牌。

默认普通设置路径：macOS 为 `~/Library/Application Support/bambu-monitor/provider.toml`；Linux 为 `$XDG_CONFIG_HOME/bambu-monitor/provider.toml`，变量无有效绝对路径时使用 `~/.config/bambu-monitor/provider.toml`。新文件权限0600、新目录0700；拒绝符号链接、危险路径和其他用户可写文件；修改已加载文件时检查外部更改，使用锁和原子替换。对不遵守锁的外部写者，最终检查到替换仍存在窄竞态，不承诺文件系统级 CAS。保存后核验失败或提交结果不明会停止后续操作并提示检查，不假报成功或删除可能已经被设置引用的新令牌。

## 日常首页

点击“开始监控”后，先核实当前登录与已选打印机仍在绑定列表，再启动同一云采集器。首页分开显示电脑采集、目标遥测和设备显示；broker 连通不代表打印机在线。喷嘴、热床和进度展示已有质量：真实 0 可有效显示，缺测为等待数据，不支持明确标注，旧值加注“旧值”。设备显示尚未接入，首页持续说明这一状态。

“停止监控”会发出停止请求，清理结束后回到可操作首页；停止请求后不继续展示排队快照为当前数据。切换打印机、重新登录、切换区域、普通设置和退出登录在采集停止后操作，避免旧连接同时工作。切换设备按 ID 重新确认；旧设备消失时不自动替换成另一台。登录失效停止无效重试，提示重新登录。

“设置”中的高级参数可以调整目标遥测证据阈值、重连初始和最大等待，保持默认通常即可。这个证据阈值不是所有字段的统一有效期；质量仍由原采集核心判定。

关闭窗口会先等待当前操作结束，再清理 HTTP、MQTT 与内存凭据；普通退出保留已明确保存的系统令牌。“退出本机登录”则移除本机对应凭据槽，不全局撤销云账号。删除失败会保留错误提示，不显示成功退出。

## 实现与验证边界

窗口主线程只处理界面，单个 owner worker 串行执行认证/密钥库/网络；没有并发采集会话，快照以单槽最新值传给窗口，不积累无限队列。关闭在途操作时撤销其导航结果并发停止请求，等待清理真实完成。系统 DNS、OS 密钥库以及库内部阻塞仍无强制总退出时限；等待期间不会声称已经退出。

本轮未增加 HTTP 网页服务、浏览器存储、外部 Pet Manager 或固件改动，也没有发布、同步或操作打印任务。三页设备布局、13 项指标、组件 ID 与版本保持原样。Tk 实际窗口交互使用合成 HTTP/凭据/MQTT 验证，真实云登录、发码、系统密钥库读写、打印机遥测与 USB/设备显示分别待验收。

手机号支持的修复与回归见[手机号登录验证](PHONE-LOGIN-VERIFICATION.md)。

自动化与手动核对结果见[向导验证](SETUP-WIZARD-VERIFICATION.md)。静态 HTML 仍是原流程演示，不是实际登录入口；实际秘密只在本地 Tk 窗口输入。
