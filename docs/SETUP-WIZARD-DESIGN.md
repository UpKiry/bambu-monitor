# 登录与设置向导设计预览

状态：用户已确认流程并授权接入，现已实现本地 Tk 窗口、真实认证/采集接入与安全配置保存。使用见[本地向导](SETUP-WIZARD.md)，实际证据见[验证记录](SETUP-WIZARD-VERIFICATION.md)。以下保留原设计约束与预览说明；预览本身仍是合成演示。

## 用户看到的流程

首次：**选择账号区域 → 登录 → 选择打印机 → 确认保存 → 监控首页**。

日常：**进入首页 → 开始监控**。首页另有切换打印机、重新登录、设置、退出登录。用户无需自己创建TOML或记住多条命令。终端与将来的图形入口可共享相同状态流程；本预览用页面展示操作与文案，不决定最终Pet Manager分发或新增HTTP服务。

| 步骤 | 用户操作 | 设计要求 |
| --- | --- | --- |
| 1 选择区域 | 明确选择中国大陆/全球 | 无默认猜测；显示账号区域说明，切区需重新登录 |
| 2 登录 | 邮箱密码或邮箱验证码 | 正式入口复用私有输入/认证；密码、验证码不写配置。验证码自动进入对应步骤，发送/重发必须用户明确操作，不自动循环 |
| 3 选择打印机 | 已知机型+设备ID尾号列表，明确选中一台 | 多台/重名按ID；即使只有一台也明确选择。未知机型诚实标明，不据列表摘要宣称在线 |
| 4 确认设置 | 确认区域/设备，选择系统密钥库或仅本次 | 自动生成普通配置；令牌仅留系统密钥库/内存。密钥库不可用时明确提示本次内存，不能显示“以后免登录” |
| 首页 | 手动开始/停止监控，修改选项 | 不默认后台启动。分别显示电脑采集、目标遥测、设备显示是否接通，不将broker连接成功当打印机在线 |

## 错误与返回

- 登录失败保留区域与非秘密选择，返回当前步骤重输；不保存密码，不清掉所有步骤要求从头来。
- 验证码未通过可以重新输入；需要新码时手动发送。当前API没有细分错误/过期证据，文案用“验证码未通过”，不伪造原因。
- 网络失败显示“检查网络后重试”，不自动重发登录/验证码。输入中的秘密不因返回上一步而持久化。
- 登录失效显示明确的“重新登录”，保留选定设备，但新登录后必须重新从绑定列表验证其存在，不自动换设备。
- 凭据库不可用说明当前为会话内存；下次需重新登录。退出登录区分清本机token与云端全局撤销。
- 目标数据超时显示缺乏遥测证据/旧值过期，不声称打印机断电。
- 取消、返回和退出均撤销在途回调资格，清理资源；停止后不再产生新请求。已有配置不能被取消中的半成品覆盖。

## 设置持久化的实施范围

实际实现：`bambu-monitor setup` 打开本地 Tk 窗口，复用现有CloudAuth、Credentials、Session和collector；现有机器可读CLI保留。向导负责完成步骤并保存明确选定设备，不复制HTTP/MQTT或质量逻辑。

配置目录、现有文件覆盖与原子写入需实现保护：默认普通设置放用户配置目录；首次先展示存储位置，写入仅含区域、设备ID、随机逻辑凭据引用和普通策略；拒绝符号链接/危险覆盖，使用原子提交；修改和取消不破坏已有设置。账号切换使用新凭据scope，验证成功后才替换当前选择。高级时限/重连选项折叠，默认值沿用当前逻辑，不让用户填写profile/UID/token。

本次采用独立 Tk 窗口，不启动HTTP服务、不修改外部宿主；普通配置通过安全设置模块保存。静态演示文件仍不接收真实秘密。现有Pet Manager尚无生产源码，不声称能直接嵌入其设置界面。

## 预览操作与边界

[HTML预览](../.build/setup-wizard-preview.html)无需服务，离线打开即可。可切区域/登录方式/设备/存储，体验返回、登录失败、网络失败、验证码分支、密钥库不可用及首页失效状态。凭据位置是只读占位，不能收集真实密码。页面禁止connect-src和form-action，未引入外部资源、fetch、localStorage或真实配置；刷新即重置演示状态。顶部和页脚持续标注合成预览。已用Node执行页面实际脚本的离线导航检查：区域未选阻止继续、登录/code分支、设备选择、密钥库回退、首页/返回/重置、切换区域清除旧选择均通过；网络与秘密输入边界检查通过。没有可用浏览器工具执行视觉渲染，页面视觉仍待用户审阅；不把脚本检查当作真实浏览器/账号通过。

颜色/排版服务电脑端设置体验，不改变ESP32三页布局、13项指标、组件ID或版本。原预览用于流程/文案确认；实际窗口已按确认流程接入，不把合成测试或真实入口实现等同于真实云验收通过。
